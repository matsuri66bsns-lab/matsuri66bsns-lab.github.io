プライバシーポリシー

bukken-radar／最終更新 2026年9月5日

bukken-radar（以下「本アプリ」）は、作者が自分自身のためだけに使う個人用ツールです。 作者以外の利用者はいません。本ポリシーは、本アプリが Google ユーザーデータをどのように 取り扱うかを説明します。

取得する情報

  • Gmail のメール内容（gmail.modify）— 利用者が自分で設定した特定のラベルが付いたメールに限り、件名・送信元・本文を読み取ります。読み取ったメールには処理済みラベルを付けます。それ以外のメールは取得しません。
  • メールの送信（gmail.send）— 評価結果のダイジェストを、利用者本人が指定した宛先へ送信するためだけに使用します。

情報の使い方

  • メール本文から物件情報（建物名、価格、面積、築年、最寄駅など）を抽出し、利用者のパソコン内のデータベースに保存します。
  • 公的機関が公開する取引価格データと比較し、価格の妥当性を評価します。
  • 評価結果を利用者本人にメールで通知します。

情報の保存と削除

  • 取得したデータは、すべて利用者本人のパソコン内にのみ保存されます。外部のサーバーへ送信・保管することはありません。
  • 認証情報（アクセストークン）も同じパソコン内のファイルに保存されます。
  • アクセスの取り消しは Google アカウントの「サードパーティ製アプリとサービス」 からいつでも行えます。取り消すと本アプリはメールにアクセスできなくなります。
  • 保存済みデータの削除は、パソコン上のデータベースファイルを削除することで行えます。

第三者への提供

取得した情報を第三者へ提供、販売、譲渡することはありません。広告目的で利用することもありません。 本アプリは作者以外に配布していないため、他の利用者のデータを扱うこともありません。

Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から取得した情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。
