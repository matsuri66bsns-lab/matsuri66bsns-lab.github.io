bukken-radar

個人が自分のために使う、中古マンション売出情報の収集・評価ツールです。

何をするツールか

不動産ポータルサイトから自分宛に届く「新着物件メール」「値下げメール」を読み取り、 物件情報を構造化して手元のパソコンに蓄積します。国土交通省の不動産情報ライブラリが公開する 取引価格データと突き合わせて推定成約価格を算出し、売出価格との差（割安度）を評価して、 自分宛のダイジェストメールで通知します。

できないこと・しないこと

  • 不動産ポータルサイトへの自動アクセス（クローリング、スクレイピング）は行いません。入力は自分宛のメール、公的API、自分で保存したページのみです。
  • 作者本人以外は利用しません。一般に公開・配布しているサービスではありません。
  • 収集した情報を第三者に提供・販売することはありません。

技術構成

  • Python で書かれたコマンドラインツール。パソコン上でのみ動作します
  • データの保存先は同じパソコン内の SQLite ファイルです
  • Gmail API を使い、指定したラベルの付いたメールのみを読み取ります
