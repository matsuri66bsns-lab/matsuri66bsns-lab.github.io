water-pipe-sizing

給水管口径計算

器具給水負荷単位法と許容摩擦損失・流速法で給水配管の口径を算定し、系統図と配管平面図を作るアプリの使い方と計算根拠です。

アプリを開く

できること

2つの入力モード

階・水廻りエリア・器具数から組み立てる「簡易定義」と、PDF図面をなぞって作図する「PDFトレース」。

自動で口径算定

入力するたびに全区間の流量・口径・損失と、全器具の残圧を再計算します。

図面と計算書

系統図（SVG / PNG）、口径を記入した配管平面図（PNG）、A4の計算書（印刷 / PDF）、CSVを出力します。

作業の流れ

  1. 設計条件：給水方式、起点圧力・起点高さ、管種、流速上限、相当長の倍率、公衆用/私室用を設定します。
  2. 入力・作図：簡易定義かPDFトレースを選んで、配管系統を入力します。
  3. 計算結果：区間別計算表と器具別残圧を確認します。画面右上のバッジに判定と主管口径が出ます。
  4. 系統図・平面図：自動生成された図を確認し、必要に応じて保存します。
  5. 計算書：「印刷 / PDF保存」でA4の計算書にします。
  6. 保存：右上の「保存」でプロジェクトファイル（.wps.json）に書き出します。

簡易定義モード

階ごとに水廻りエリア（便所、給湯室など）を置き、エリアごとに器具の種類と個数を入れます。次の形の系統を自動で組み立てます。

水源 ─主管─ 立管 ─(各階)─ 横引き枝管 ─ エリア ─ 器具間配管 … ─ 器具枝管 ─ 器具
  • 「階構成の一括設定」で階数と階高を指定すると、1番目の階のエリア構成を全階にコピーして作り直します。
  • 「立管からの距離」は立管からエリア入口までの横引き長さ、「器具間隔」はエリア内の器具どうしの間隔です。
  • 下向き供給（高置水槽）では最上階から立管を下ろします。起点圧力は通常 0、起点の高さに水槽の低水位を入れます。

PDFトレースモード

PDFの各ページを1つの階として扱います。ページごとに階名・FL・配管高さ・縮尺を右パネルで設定してください。PDFがなくても白紙ページで作図できます。

計算方法

1. 同時使用流量

各区間の下流にある器具の給水負荷単位を合計し、SHASE-S 206 の同時使用流量線図（①洗浄弁が多い場合、②洗浄タンクが多い場合）から流量を求めます。線図は「自動」にすると、下流に洗浄弁がある区間で①を使います。下流の器具が1個の区間は器具の給水流量とし、複数でも最大器具流量を下回らないようにします。

2. 許容摩擦損失

R = (起点圧力 − 器具の最低必要圧力 − ρg × 高低差) ÷ 水源から器具までの相当長

器具ごとに R を求め、各区間ではその下流にある器具の最小値を使います。相当長は「実長 × 相当長の倍率」です。

3. 口径の選定

h/L = 10.666 · C−1.852 · D−4.87 · Q1.852　[m/m]　（ρg = 9.80665 kPa/m）

流速 ≤ 上限 かつ 摩擦損失 ≤ R を満たす最小口径を選び、下流より細くならないよう補正します。器具単独の枝管は、設定により器具の接続口径を優先します（流速超過は「注意」と表示）。

4. 検算

決定口径で各器具の残圧（起点圧力 − 摩擦損失の累計 − 静水頭）を求め、必要圧力を下回る器具を「圧力不足」とします。全器具のうち最も厳しい値が「必要起点圧力」です。

初期値と注意点

  • 器具給水負荷単位は SHASE-S 206 の表、同時使用流量線図は Hunter 曲線系の数表を補間した近似値です。
  • 器具の給水流量・必要圧力・接続口径、ライニング鋼管と架橋ポリエチレン管の内径は標準的な参考値です。採用製品の値に合わせて「マスタ」で調整してください。
  • 樹枝状配管のみ対応です。ループになった区間は計算から除外し、警告を出します。
  • 水道メーター・逆流防止器・減圧弁など機器の損失は、現時点では個別に入力できません。相当長の倍率か起点圧力で見込んでください。

本アプリの結果は設計の補助です。最終的な口径は、水道事業体の給水装置工事設計基準と採用製品の資料で確認してください。
